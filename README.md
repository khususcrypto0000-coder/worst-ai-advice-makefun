Entry for the [Worst AI Advice: The 48-Hour Tight Line Open](https://make.fun/bounty/u-steady-ibis-48-6610-worst-ai-advice-the-48-hour-9d91c580) bounty on [make.fun](https://make.fun). The task: write one line of the worst possible advice an AI could give, in 140 characters or fewer, judged by a deadpan comedy critic on how funny the bad advice is, how tight the line is, how much it sounds like a real AI assistant, and how concrete it is.


## The entry

My line is an original one-sentence answer to a dead car battery, delivered in the confident, tidy voice of a helpful AI assistant — complete with a bogus fix that sounds just plausible enough to follow and immediately regret. It names a real, everyday situation (a car that will not start) and a single concrete action, so the badness is vivid rather than vague, and the whole joke lands in one short line with no wasted words.

## How it works

`main.py` is standard library only. It holds the entry as a string constant and writes it to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), exiting 0 on success. The output is deterministic: every run writes the exact same bytes.

```sh
python3 main.py
```
